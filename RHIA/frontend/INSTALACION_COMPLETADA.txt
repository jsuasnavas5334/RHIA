                         PRÓXIMOS PASOS - DEPLOYMENT
════════════════════════════════════════════════════════════════════════════════

La carpeta dist/ contiene tu aplicación lista para producción.

OPCIÓN 1: VERCEL (Recomendado - Más fácil)
  1. Instalar Vercel CLI:      npm install -g vercel
  2. Ejecutar:                 vercel deploy
  3. Seguir los pasos del setup wizard

OPCIÓN 2: NETLIFY
  1. Instalar Netlify CLI:     npm install -g netlify-cli
  2. Ejecutar:                 netlify deploy --prod --dir=dist
  3. Autorizar y confirmar

OPCIÓN 3: TU SERVIDOR (AWS, DigitalOcean, etc.)
  1. Subir carpeta dist/ a tu servidor web
  2. Configurar web server para servir index.html (single-page app)
  3. Configurar variables de entorno (API_BASE_URL)

VARIABLES DE ENTORNO (.env):
  VITE_API_BASE_URL=https://tu-api.com/api
