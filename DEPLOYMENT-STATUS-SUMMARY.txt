================================================================================
DOCKER RESTART POLICY SUMMARY
================================================================================

Docker containers are configured with:
  restart: unless-stopped

This means:
- Containers automatically restart if they crash
- Containers automatically restart if Docker daemon restarts
- Containers do NOT restart if they were manually stopped
- Containers do NOT restart if the system reboots (UNLESS Task Scheduler task is registered)

The Windows Task Scheduler task ensures services start after Windows reboot.
